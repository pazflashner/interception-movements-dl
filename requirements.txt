# Exact pins. Loose bounds are what let this environment drift.

# Training is seeded and runs with deterministic=True, but that guarantees
# reproducibility only for a fixed library stack. Re-running the confirmatory
# study on a newer NumPy/PyTorch reproduces the spline arm exactly (it is
# deterministic linear algebra) while the neural weights diverge completely --
# same fold, dimension, seed and stopping epoch, zero of sixteen tensors
# identical. Change these versions only deliberately, and expect the published
# neural figures to move if you do.
#

#     Python 3.13.5, numpy 2.3.4, torch 2.12.0+cpu
