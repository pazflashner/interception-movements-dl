# Archived movement-only study - not current

This local folder contains the code-adjacent artifacts, reports, dashboards,
and exploratory documents that existed at Git commit `b2cfcd6`.

They use the superseded primary representation:

- finger movement onset to recorded arrival;
- `Too early` trials incorrectly excluded as if the label meant movement before
  the target-motion go signal;
- latent dimensions 2, 3, and 8.

The files are retained only for provenance and comparison. They are ignored by
Git at their archived location and must not be used as current results. The
complete tracked snapshot remains recoverable from commit `b2cfcd6`.

The current study lives in `studies/strategy_window_comparison/` and fairly
compares movement-only with target-motion-onset-to-arrival representations on
the same corrected trial cohort.
