# Scientific figures retained for portable report builds

Generated by `python -m production.course_figures`.

- `trajectory_energy.png`: cohort means from the `raw_rms` rows of
  `../trajectory_distribution_2026_09_13/summary.csv`; both dimensions and all
  four compact models. No uncertainty intervals or capacity tests are implied.
- `fingerprint_controls.png`: exact mean-KS values from the CVAE fingerprint
  control summary and `../audit_2026_09_08/uvae8_fingerprint_summary.csv`.
- `generated_paths.png`: subject01, chosen by identifier rather than model
  performance, fold 2, n=8, neural seed 42 and the frozen spline sampling
  realization. Each panel displays the first 30 stored paths; its solid curve
  averages all 90 recorded query or 120 generated paths. Axes have equal spatial
  scale and shared limits. Paths come from the independently checked NPZ files
  in the local ignored `../assets/trajectory_distribution_2026_09_13/` cache.

These are plotted measurements/model outputs, not generated illustrations.
The original task illustration is retained separately in `presentation_assets/`.
Typeset equations are regenerated from `report_equations.py` in the ignored
assets directory and embedded in the report and presentation.
